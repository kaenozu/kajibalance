# KajiBalance UI モックイメージ

## 1. 画面遷移図

```
[スプラッシュ]
     ↓
[ログイン] ←→ [新規登録]
     ↓
[ペア設定] ← 招待コード入力 or 生成
     ↓
[ホーム（ダッシュボード）]
  ┌────┼────┐
  ↓    ↓    ↓
[タスク] [分析] [設定]
```
