# KajiBalance 開発ロードマップ

## 全体方針

**まず動くものを作る → ユーザー反応を見る → 改善する**
技術選定も段階的にアップグレードする。最初から完璧を目指さない。

```
Phase 1 (MVP)     Phase 2            Phase 3
   Glide            Flutter            LLM追加
   2週間            2〜3ヶ月           ユーザー次第
```

---

## Phase 1: MVP（2週間） — Glideで高速プロトタイプ

### 目標
- コア機能（タスク共有＋負担グラフ＋リマインダー）の動作確認
- 実際の夫婦数組に使ってもらいフィードバック取得
- 需要の本検証

### やること

| 週 | タスク | 成果物 |
|---|---|---|
| Week 1 | Glideプロジェクト作成、認証設定、ペア設定フロー | ログイン〜ペア設定まで動く |
| Week 1 | タスクマスター（約30件のコアタスク）のスプレッドシート作成、割り当て機能 | タスク追加/担当割り当て/完了チェック（基本セット） |
| Week 2 | タスクマスター拡充（残り約70件）、カテゴリ分類の調整 | 100件タスクが選択可能に |
| Week 2 | グラフダッシュボード（Glide Charts）、リマインダー設定 | 負担率の可視化 |
| Week 2 | 定型文アラート機能、感謝ポイント機能 | アラート表示・感謝送信 |
| Week 2 | 社内テスト・修正・リリース | 公開（PWA or iOS/Android） |

### マイルストーン
- 3組の夫婦に使ってもらいフィードバック収集
- DAU 100達成

### Phase 1リリース前チェックリスト
- [ ] プライバシーポリシー作成
- [ ] 利用規約作成
- [ ] データエクスポート機能（最低限CSV）の実装
- [ ] アカウント削除フローの実装

---

## Phase 2: 本格開発（2〜3ヶ月） — Flutter + Firebase移行

### 移行判断基準
Phase 1で以下を確認できたら移行する：
- DAU 1,000以上 or 継続率50%以上
- 「もっと使いやすいUIが欲しい」という声が複数
- グラフや集計のカスタマイズ要求

### 移行内容

| 項目 | 内容 | 目安 |
|---|---|---|
| Flutter移行 | GlideからFlutterアプリに書き換え | 4〜6週間 |
| Firebase導入 | Firestore + Auth + Cloud Functions + Analytics | 1週間 |
| UI改善 | モック通りの本格UI実装 | 2週間 |
| テンプレート機能 | 新婚/子育て/同棲向けプリセット | 1週間 |
| プレミアム課金 | RevenueCat導入、サブスク実装 | 1週間 |
| テストリリース | クローズドβ → 公開 | 2週間 |

### 目標数値
- DAU 5,000
- プレミアム転換率 5%
- レビュー ★4.0以上

---

## Phase 3: LLM拡張（ユーザー次第）

### 判断基準
- DAU 10,000超え or プレミアム課金が月収20万円を超えた
- 「献立提案が欲しい」「アドバイスを自動で欲しい」という要望が複数

### 追加機能

| 機能 | 技術 | 優先度 |
|---|---|---|
| 献立提案（食材手入力） | Gemini 1.5 Flash API | ★★★ |
| 週間AIアドバイス | 同上 | ★★ |
| 冷蔵庫写真認識 | Google Cloud Vision + Gemini | ★★ |
| 音声タスク追加 | Whisper (ローカル) | ★ |

### 注意点
- LLMはプレミアム限定機能とする
- APIコストを抑えるため、Gemini 1.5 Flash の無料枠/低価格帯を活用
- プロンプト設計を最適化し、無駄な呼び出しを削減

## リリース戦略

### タイミング
- Phase 1（MVP）: **即リリース可能**。今週中に公開
- Phase 2: 夏〜秋（新生活慣れの時期？よりは、家事負担が増える年末年始？検討）
- Phase 3: 2026年内 or ユーザー数次第

### プロモーション
- X/Instagramで「見えない家事あるある」投稿 → アプリ誘導
- 夫婦カウンセラー・子育てインフルエンサーとのコラボ
