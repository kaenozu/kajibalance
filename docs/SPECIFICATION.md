# KajiBalance 仕様書

## アプリ名（仮）

**KajiBalance（カジバランス）** — 見えない家事を可視化して、夫婦の負担を公平に

---

## 1. アプリ概要

### コンセプト
物理的な家事に加えて「見えない家事（メンタルロード）」を数値化・共有し、夫婦間の負担バランスを可視化するツール。
単なるToDo共有ではなく、**公平感・感謝・会話のきっかけ**を提供する。

### コアバリュー
- 「私ばかりやっている」を数値で解消
- メンタル負担（献立を考える・予定を管理する等）も「家事」としてカウント
- 感謝のリアクションでモチベーション維持

### ターゲットユーザー
- 共働き夫婦（20〜40代、女性メインだが男性も巻き込む）
- 子育て世帯（子どもあり）
- 同棲・新婚カップル（分担ルールを決めたい）
- 家事分担にモヤモヤしているすべてのカップル

## 2. 機能一覧

### Phase 1（MVP） — LLM完全不要

| # | 機能 | 説明 | 優先度 |
|---|---|---|---|
| 1 | 家事タスク共有ボード | 夫婦でリアルタイム同期。カテゴリ（掃除/料理/買い物/育児/ペット/手続き）分類 | ★★★ |
| 2 | 負担スコア自動集計 | 各タスクに事前定義された「物理負担点」「メンタル負担点」を持ち、担当者割り当てで自動グラフ化 | ★★★ |
| 3 | 週間/月間負担バランスグラフ | 円グラフ・レーダーチャートで可視化。2軸（物理/メンタル）表示 | ★★★ |
| 4 | タスクリマインダー | 毎日/毎週/毎月の繰り返しタスクを誰が担当かアサイン＋プッシュ通知 | ★★★ |
| 5 | 感謝ポイント機能 | タスク完了時に「ありがとう」スタンプ送信。累計表示 | ★★ |
| 6 | バランス指摘（定型文） | 負担率が閾値を超えたら定型メッセージ表示（LLM不使用） | ★★ |

### Phase 2 — 拡張機能

| # | 機能 | 説明 |
|---|---|---|
| 7 | レシピ提案 | 手入力食材＋固定レシピDBマッチング |
| 8 | 賞味期限・ストック管理 | 手動登録＋期限通知 |
| 9 | 子ども予定共有 | 学校行事・持ち物チェックリスト |
| 10 | メンタルロード日記 | 1行日記＋傾向グラフ |
| 11 | テンプレート機能 | 新婚向け・子育て向けなど初期設定テンプレート |

### Phase 3 — LLM活用（プレミアム）

| # | 機能 | 説明 |
|---|---|---|
| 12 | AI献立提案 | 冷蔵庫写真 or 食材リストからLLMが献立生成 |
| 13 | AIアドバイス | 週間振り返り＋改善提案をLLMが自然文で生成 |
| 14 | 音声タスク追加 | 音声認識でタスク追加 |

## 3. 画面構成

### 3.1 ホーム（ダッシュボード）
- 今週の負担バランスサマリー（グラフ）
- 今日のタスクリスト（自分担当）
- 最新の感謝ポイント表示
- バランスアラート（あれば）

### 3.2 タスク一覧・追加
- タスク追加フォーム（名称/カテゴリ/担当者/頻度/メモ）
- 未完了タスク一覧＋完了チェック
- カテゴリフィルター

### 3.3 グラフ・分析
- 週・月単位の負担率グラフ
- 個人別：カテゴリ別負担内訳
- バランスアラート履歴

### 3.4 設定
- 夫婦アカウント連携（招待コード）
- テンプレート選択
- 通知設定

## 4. マネタイズ

### 基本無料（フリーミアム）
コア機能（タスク共有・グラフ・リマインダー・感謝ポイント）は無料。

### プレミアムプラン（月額480円 / 年額4,800円）
| 機能 | 無料 | プレミアム |
|---|---|---|
| タスク共有 | 10件まで | 無制限 |
| グラフ表示 | 週間のみ | 月間＋年間＋カテゴリ別 |
| バランス指摘 | 基本のみ | 詳細分析＋改善提案 |
| レシピ提案 | - | ○ |
| 賞味期限管理 | - | ○ |
| テンプレート | 1種類 | 全種類 |
| 広告 | 表示 | 非表示 |
| ログ履歴 | 1ヶ月 | 無制限 |

### 課金ルール（詳細）
- 無料トライアル: なし（または14日間無料を検討）
- 月額購入: 課金日は購入日。解約は次回課金日まで有効
- 年額購入: 購入日から12ヶ月。自動更新、解約はいつでも可能
- プラットフォーム縛り: iOS/Androidそれぞれのストア規約に準拠（RevenueCat導入時に自動処理）
- キャンセル後のデータ: アーカイブ化（編集不可、閲覧のみ）または削除（ユーザー選択）

### 広告（無料ユーザー向け）
- バナー広告（下部、控えめ）
- 関連性の高い広告（時短家電・食材宅配・掃除グッズ・収納用品）

### アフィリエイト
- Amazon / 楽天の家事関連商品リンク
- 冷凍宅食・ミールキット紹介

## 5. 差別化ポイント

| 観点 | 既存アプリ（CAJICO / Yieto / Sweepy等） | KajiBalance |
|---|---|---|
| 負担の種類 | 時間のみ | 物理＋メンタルの2軸 |
| メンタルロード | 非対応 | 専用スコア＋可視化 |
| AI活用 | 無し | Phase 3で差別化 |
| 感謝機能 | 無し or 弱い | 「ありがとう」ポイント |
| 夫婦関係改善 | 間接的 | 設計上のコアバリュー |

## 6. プライバシー・法務（必須対応）

### 取り扱うデータの特性
家事分担データは「夫婦の生活リズム」「子どもの育児状況」「家計の時間配分」等、極めてセンシティブな情報を含む。以下の点を設計段階から考慮する。

### 収集する個人情報（最小限）
- メールアドレス（認証のため）
- 表示名（夫婦間での識別のため）
- タスク実績（ペア内のみ共有、サーバー側では暗号化推奨）
- 感謝ポイント（ペア内のみ共有）

### 必須となる規約類
| 規約 | 説明 | タイミング |
|---|---|---|
| プライバシーポリシー | データ収集範囲・保存期間・第三者提供の有無・削除方法 | Phase 1リリース前 |
| 利用規約 | アプリの利用条件・禁止事項・免責 | Phase 1リリース前 |
| 特定商取引法に基づく表記 | プレミアム課金を行う場合（法人としての表記） | Phase 2（課金実装時） |

### データ保持・削除ポリシー（方針）
- 無料ユーザー: 最終ログインから12ヶ月以上経過したアカウントは anonymize または削除
- プレミアム解約後: 課金終了日から3ヶ月経過後にユーザーが削除を選択可能
- ユーザー自身の削除リクエスト: 30日以内に全データ削除を完了
- タスクデータのエクスポート機能（CSV/JSON）はユーザーがいつでも取得可能に

### 第三者提供
- Google（Glide/Firebase利用時）: ホスティング・認証目的でのデータ処理
- 上記以外への第三者提供: 原則なし（統計分析に使用する場合も個別同意を取得）

## 7. ユースケース

### ケース1：共働き・子育て世帯（30代）
- 朝：アプリを開くと「今日のタスク：夕飯準備（妻）、洗濯（夫）」
- 週末：グラフを見て「今週は妻のメンタル負担が72%。夕飯計画を見直そう」と話し合い

### ケース2：新婚カップル
- テンプレート「新婚おすすめ配分」を選択。
- 毎日のお互いのタスクが可視化され、感謝ポイントでポジティブな習慣ができる。

### ケース3：同棲中のカップル
- 最初は軽い気持ちで始める。続けるうちに「やってくれていること」への感謝が増える。
